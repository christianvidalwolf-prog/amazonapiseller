# Mantas polares de microfibra ROCKING GIFTS — familia de variantes (2026-10-04)

Una familia `PARENT-MANTAS-POLARES-RG` (productType `BLANKET`, tema `PATTERN_NAME/COLOR_NAME`: dibujo / color) en ES, DE, FR e IT con las 22 mantas polares de microfibra de 125x150 cm vivas.

- `spec.py` — dibujo y color de cada manta, con traducciones; excluidos con el motivo.
- `families.py` — título, viñetas y descripción del padre en los 4 idiomas.
- `run.py preview|submit [ES,DE,...]` — mismo flujo que `../teteras/run.py`, más el tipo de tejido obligatorio en `BLANKET` (`fabric_type`): el declarado o "100% poliéster (microfibra polar)".

Excluidas: 17 mantas en la lista de borrado, las de la marca CIAL LAMA y otros productos (mantas sudadera, plaids de algodón, mantas para mascotas, peluches con manta).
